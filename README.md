

# Projeto "Dani Sushi Page"

Este repositório contem *uma landing page*, desenvolvida para uso na bio do *Instagram*, apresentando informações essenciais sobre a empresa e direcionando possíveis clientes de forma rápida e eficaz para o nosso *Whatsapp*.

---

- **Landing page Instagram**

👉 https://danisushii.com.br

---

**Tecnologias utilizadas**
- HTML, CSS e JavaScript (vanilla)
- Vite
- GSAP + ScrollTrigger
- Lenis

**Como rodar**
```bash
npm install
npm run dev     # servidor local
npm run build   # build de produção em dist/
```
